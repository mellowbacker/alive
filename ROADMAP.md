# Roadmap

This roadmap is non-binding. It describes possible work, not guaranteed deliverables or price catalysts.

## Phase 0 — Prepare
- [x] Publish the public project repository structure.
- [x] Publish the manifesto and fair-launch policy.
- [ ] Add final branding assets.
- [ ] Publish creator wallet before launch.
- [ ] Review launch configuration and disclosures.

## Phase 1 — Birth
- [ ] Launch publicly through Pump.fun.
- [ ] Publish mint address and launch transaction.
- [ ] Publish the official token page link.
- [ ] Complete token facts and actual fee disclosures.
- [ ] Invite independent review.

## Phase 2 — Independence
- [ ] Accept community issues and pull requests.
- [ ] Publish material project updates.
- [ ] Maintain a public record of corrections and disclosures.
- [ ] Allow independent community initiatives.

## Phase 3 — Community evolution
- [ ] Consider community-built tools and integrations.
- [ ] Consider independent creative projects.
- [ ] Review proposals openly, without promising implementation.

There is no guaranteed timetable. No phase guarantees token demand, liquidity, price performance, or exchange access.
