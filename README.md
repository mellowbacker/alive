# ALIVE ($ALIVE)
### No owner. No promises. Just life.

ALIVE is a community-oriented memecoin experiment launched through Pump.fun. Its founding principle is simple: the creator does not buy tokens and does not reserve a token allocation for themselves. After launch, the project is open to independent participation.

**ALIVE is a meme/community project, not an investment product.** There is no promise of price appreciation, liquidity, exchange listings, development, or financial return.

## Project principles

- **No creator purchase:** the creator's disclosed wallet will not intentionally buy $ALIVE.
- **No creator allocation:** no tokens are privately reserved for the creator.
- **No private presale or insider round:** the project intends a public launch.
- **Public documentation:** project information and changes are recorded in this repository.
- **Community participation:** anyone can suggest ideas, build independent tools, or contribute.
- **No price promises:** no targets, guaranteed returns, or claims of inevitable growth.
- **No artificial activity:** no wash trading, fake volume, coordinated deceptive promotion, or bot-driven trading.

These are project commitments, not proof by themselves. Verify launch settings and wallet activity independently on-chain.

## How to verify the no-buy commitment

1. Compare the creator wallet published in `docs/TRANSPARENCY.md` with the wallet shown in the launch transaction.
2. Inspect the wallet's transactions and token-account activity using independent Solana explorers.
3. Check whether the creator wallet acquired tokens directly or through related wallets. Wallet attribution is not always conclusive.
4. Review creator-fee settings and any fee withdrawals; disclose them accurately.
5. Report discrepancies with transaction links and evidence.

A statement that the creator did not buy is not a guarantee that no associated person or wallet bought. Do not claim stronger verification than the evidence supports.
