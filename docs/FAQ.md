# FAQ

### Does the developer buy ALIVE?
The project's stated commitment is that the creator will not intentionally buy tokens. Publish the creator wallet and let people inspect on-chain activity. Do not claim this proves that no related wallet acquired tokens.

### Does the developer receive an allocation?
No creator allocation is intended. Publish the launch configuration and on-chain evidence where available.

### Who owns ALIVE?
The token is not represented as owned by a company or community organization. The creator does not claim authority over independent holders or community members. Administrative control over this GitHub repository is separate from token ownership.

### Is ALIVE an investment?
No. It is a speculative memecoin experiment. It may lose all value.

### What does GitHub do?
GitHub provides public documentation, change history, and a place for voluntary contributions. It does not control the token or guarantee decentralization.

### Is there a roadmap?
There are possible community activities, but no guaranteed development schedule or outcome.
