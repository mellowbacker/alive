# Launch checklist

## Before launch
- [ ] Confirm ticker/name availability and avoid impersonating another project.
- [ ] Finalize logo and banner; ensure rights to all assets.
- [ ] Create the public GitHub repository.
- [ ] Publish manifesto, fair-launch policy, disclaimer, and transparency page.
- [ ] Publish creator wallet address before launch.
- [ ] Review Pump.fun's current launch interface, fees, and settings.
- [ ] Confirm no creator allocation or intentional creator purchase is planned.
- [ ] Prepare accurate social copy; do not promise returns or price targets.

## At launch
- [ ] Launch through the intended official Pump.fun interface.
- [ ] Save the mint address and transaction signature.
- [ ] Save the official token page URL.
- [ ] Record actual creator-fee configuration.
- [ ] Do not claim a setting is enabled/disabled until verified.

## After launch
- [ ] Update `docs/TOKEN-FACTS.md`.
- [ ] Update `docs/TRANSPARENCY.md`.
- [ ] Add explorer links and transaction evidence.
- [ ] Check that website and social links point to the correct project.
- [ ] Invite independent review.
- [ ] Correct any errors publicly.

## Never do
- [ ] Buy tokens from the creator wallet while claiming no creator purchases.
- [ ] Hide creator-associated wallets or material fee arrangements.
- [ ] Manufacture volume, holders, engagement, or testimonials.
- [ ] Promise listings, returns, price targets, or guaranteed liquidity.
