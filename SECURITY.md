# Security policy

ALIVE's repository is primarily documentation and a small static website. It is not a wallet, exchange, custody service, or trading bot.

## Reporting
Please do not publish exploitable vulnerabilities, private keys, seed phrases, or personal information in public issues. Open a private security advisory through GitHub's **Security** tab if enabled for this repository. If private advisories are unavailable, contact the maintainers through a verified channel listed in the repository.

## Safety rules
- Never share a seed phrase or private key with anyone.
- ALIVE maintainers will never need your seed phrase.
- Verify mint addresses and links independently.
- Beware of impersonators, fake airdrops, and unofficial support accounts.
- Do not run scripts or connect wallets based solely on a social-media message.

There is no promise of response time or security audit.
